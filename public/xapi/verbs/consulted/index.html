Verb

Governed · Profile version 0.1.0

Normative meaning

A deliberate learner request for access to an Artifact InformationSource.

Boundaries

It does not imply delivery, attention, comprehension, agreement, completion, learning, engagement, diligence, thoroughness, or quality of review. Each renewed deliberate consultation is a separate occurrence using the same Verb.

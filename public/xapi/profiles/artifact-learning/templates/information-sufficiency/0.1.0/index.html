Information Sufficiency Declaration

Canonical IRI
https://artifactlearning.com/xapi/profiles/artifact-learning/templates/information-sufficiency/0.1.0
Profile version
0.1.0
Status
Governed · version-sensitive

Purpose

Records one explicit subjective sufficient or insufficient declaration about a DecisionContext without success or completion semantics.

Determining Concepts

  • Verb: declared information sufficiency
  • Object Activity Type: DecisionContext

Key governed constraints

  • result.response is included and is exactly sufficient or insufficient.
  • An applicable Experience registration and Profile category are included.
  • Success, completion, score, duration, Result extensions, other context Activities, comparison-group, object description and extensions, and attachments are excluded.

Artifact producer requirements

The declaration is subjective and must not be produced or interpreted as objective sufficiency, correctness, readiness, competence, completion, or success.
